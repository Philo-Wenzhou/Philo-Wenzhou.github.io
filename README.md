# Wenxing Yi — personal academic website

Live: https://philo-wenzhou.github.io/

Static, responsive HTML/CSS/JavaScript. English is the default; the language button switches to Chinese and remembers the selection. Research rows expand to show context and public code links. No build step or third-party scripts are required.

## Maintain

- Homepage and English content: `index.html`
- Chinese content: `data-zh` attributes in `index.html`
- Styles: `assets/site.css`
- Language control: `assets/site.js`
- Former homepage: `ben.html` (existing CSS, images and note pages remain in place)

Preview with `python -m http.server 8765 --bind 127.0.0.1` in this directory.
